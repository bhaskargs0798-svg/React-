# My React Portfolio

## About the Project

This is my personal portfolio website developed using React. It showcases my profile, skills, projects, resume, and contact information.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Features

- About Me section
- Projects section
- Skills section
- Resume download
- Contact section
- Responsive design for mobile and desktop
- Reusable React components

## How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd my-portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.

## Production Build

To create a production build, run:

```bash
npm run build
```

## Challenges and Solutions

- **Responsive Design:** Used CSS media queries to make the website work on different screen sizes.
- **Component Structure:** Divided the website into reusable React components.
- **Image Handling:** Stored profile and resume files in the public folder and referenced them from the application.
